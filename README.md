# Site Cynder Filmes

Site oficial da Cynder Filmes — https://cynderfilmes.com.br

- Páginas: `index.html`, `trabalhos.html`, `casamentos.html`, `sobre.html`, `contato.html`, `privacidade.html`
- Imagens e vídeos: pasta `assets/`
- `dcl.js`: desenha as páginas no navegador (React)
- `_build/`: arquivos de origem e o script que gera as páginas

Hospedado no Cloudflare Pages: cada envio para a branch `main` publica o site automaticamente.
